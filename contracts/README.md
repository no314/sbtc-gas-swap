# contracts

Clarinet project for `sbtc-gas-swap-v1`.

- `contracts/sbtc-gas-swap-v1.clar`: the mainnet contract. Pool principals hardcoded, rate immutable.
- `contracts/sbtc-gas-swap-v1-simnet.clar`: generated by `scripts/build-simnet-variant.mjs`. Same contract with the three pool principals and the sponsor keyword swapped for mocks. `tests/variant.test.ts` proves the two differ only in those tokens.
- `contracts/mocks/`: simnet stand-ins for the pools (same integer arithmetic and error codes as the deployed pools, settable reserves) and for `tx-sponsor?`, which simnet cannot set.
- `.cache/requirements/`: verbatim deployed sources of every mainnet contract the swap touches (Bitflow XYK, Velar, Bitflow DLMM, sBTC), so `clarinet check` type-checks the real call signatures offline. Fetched 2026-09-05; `../docs/mainnet-sources/MANIFEST.json` has the hashes.

```
npm install
npm run check        # clarinet check, 6 contracts
npm test             # vitest + simnet, 37 tests
npm run test:costs   # writes costs-reports.json
node scripts/build-simnet-variant.mjs   # regenerate the simnet variant after editing the contract
```

Known test gap: `tx-sponsor?` is always `none` in simnet, so the real sponsor path is covered only by the mainnet dust swap (see `docs/contract.md`).
